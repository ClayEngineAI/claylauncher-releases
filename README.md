# Clay Launcher

[Download for Windows x64](https://github.com/ClayEngineAI/claylauncher-releases/releases/latest/download/ClayLauncher.exe) · [Download for Apple Silicon](https://github.com/ClayEngineAI/claylauncher-releases/releases/latest/download/ClayLauncher-macOS.zip) · [Download for Linux x86-64](https://github.com/ClayEngineAI/claylauncher-releases/releases/latest/download/ClayLauncher-linux-x64.tar.gz)

On Windows, open `ClayLauncher.exe`. On macOS, unzip the download and move **Clay Launcher** to Applications. On a Linux x86-64 desktop with GTK 3, extract the tarball into a user-owned folder and run `./ClayLauncher/claylauncher`. Games appear when a release for your platform is available.

The launcher opens the Clay beta catalog and checks for updates automatically. If you installed v0.1.1, download the new launcher once to switch to the current update feed.
